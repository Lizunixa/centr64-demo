# Ц.Е.Н.Т.Р. — демонстрация концепций сайта

Репозиторий содержит две демонстрационные HTML-концепции сайта страйкбольного клуба «Ц.Е.Н.Т.Р.» (Саратов).

## Просмотр

- `index.html` — стартовая страница с выбором концепции.
- `variant-1/index.html` — тактическая концепция с лазерной заставкой и прицелом.
- `variant-2/index.html` — игровая концепция Game UI с жёлтыми акцентами.

Откройте `index.html` в браузере либо опубликуйте репозиторий через GitHub Pages. После публикации посетитель сможет перейти на стартовую страницу и открыть любой из двух вариантов. Страницы адаптированы под разные размеры экранов.

## Важно: это демонстрационный проект

Проект создан для предварительного показа и согласования визуальной концепции. Он **не является готовым официальным сайтом клуба** и не должен восприниматься как подтверждение действующих условий или услуг.

Перед запуском необходимо:

- проверить и согласовать все тексты, цены, адреса, телефоны, ссылки и сведения о клубе;
- заменить демонстрационные фотографии на согласованные фотографии клуба или материалы с подходящими правами использования;
- подключить и протестировать реальную отправку заявок из формы;
- добавить настоящую карту и проверить её расположение;
- проверить сайт на целевых устройствах и браузерах.

### Ограничения текущей демонстрации

- Форма записи не отправляет заявки на сервер. В игровой версии при отправке показывается уведомление о демонстрационном режиме.
- Блок карты является визуальной заглушкой и не подключён к картографическому сервису.
- Часть изображений, шрифтов и иконок загружается со сторонних CDN и внешних сервисов. Для их отображения требуется подключение к интернету; адреса ресурсов указаны непосредственно в HTML.
- Внешние фотографии используются как временные иллюстрации и не являются подтверждением того, что на них изображён клуб или его площадка.

## Технологии

- HTML5
- CSS3 (адаптивная вёрстка, переходы и анимации)
- JavaScript (интерактивные элементы интерфейса)
- Google Fonts и Font Awesome через внешние CDN

Сборка и установка зависимостей не требуются. Для локального просмотра достаточно открыть `index.html` в браузере.

## Публикация через GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите **содержимое архива** в корень репозитория — файл `index.html`, папки `variant-1` и `variant-2`, а также остальные файлы.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем сохраните настройки.
6. После публикации GitHub Pages выдаст ссылку на стартовую страницу с выбором двух концепций.

Учтите: опубликованная через GitHub Pages страница обычно общедоступна. Не размещайте в репозитории персональные данные, пароли, ключи API или другую конфиденциальную информацию.

Внешние изображения, шрифты и библиотеки принадлежат соответствующим правообладателям и используются на условиях их собственных лицензий и правил. Перед коммерческим запуском проверьте права на каждый используемый материал и при необходимости замените его.
